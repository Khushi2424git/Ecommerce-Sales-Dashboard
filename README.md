# 🛒 EzMart – E-commerce Sales Dashboard

## 📊 Project Overview

This project is an interactive **E-commerce Sales Dashboard** created to analyze and present important business insights in a simple and visually appealing way.

The dashboard focuses on key business performance indicators, including sales, orders, customers, average order value, delivery performance, and customer reviews.

The main objective of this project is to turn raw business data into meaningful insights that can help understand sales trends, customer behaviour, and overall business performance.

## 🎯 Dashboard Highlights

The dashboard includes the following key performance indicators (KPIs):

- **Total Sales:** 26.82M
- **Total Orders:** 112.3K
- **Total Customers:** 99.44K
- **Average Order Value (AOV):** 238.86
- **Delivery Performance:** 97.02%

## 📈 Visualizations & Analysis

Different charts have been used to make the data easier to understand and compare.

- **Monthly Sales Trend:** Tracks sales performance across all 12 months.
- **Payment Methods Analysis:** Shows the distribution of different payment methods, including cash on delivery, credit card, debit card, and other payment types.
- **Customer Review Ratings:** Displays the distribution of customer reviews based on ratings.
- **Customer Ratings Analysis:** Compares the number of customers across different rating categories.
- **Year-wise Average Sales:** Provides a comparison of average sales between 2017 and 2018.

## 🎛️ Interactive Features

To make the dashboard more useful for data exploration, interactive filters have been included.

- Payment Type Filter
- Customer Review Score Filter

These filters allow users to explore the dashboard based on selected categories and gain more focused insights.
